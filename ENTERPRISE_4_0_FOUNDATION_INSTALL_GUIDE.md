# GPT Quant Enterprise 4.0 Foundation Pack

## 安裝順序

1. 解壓並覆蓋 GitHub 專案。
2. Commit、Push。
3. Supabase 執行：
   `supabase/ENTERPRISE_4_0_FOUNDATION_COPY_PASTE_SETUP.sql`
4. 成功訊息：
   `GPT Quant Enterprise 4.0 Foundation Pack setup complete`
5. 執行：
   `Enterprise 4.0 Foundation Validation`
6. 執行：
   `Enterprise 4.0 Foundation Run`
7. 執行 GitHub Pages 部署。
8. 網站按 `Ctrl + Shift + R`。

## Foundation 內容

- Portfolio Registry
- Strategy Registry
- Strategy Version Registry
- Portfolio-Strategy Mapping
- Enterprise Run Tracking
- Run Stage Tracking
- Audit Log
- Market Regime Foundation
- Strategy-Regime Allocation
- 3.x Compatibility Views
- Release Status
- PAPER ONLY 安全模式

## 注意

此 Pack 不包含 4.0 OMS、Central Risk Governor 或券商下單。
實盤交易保持關閉。
